# WB-OZON-AI-TEAM

**ИИ-команда для селлеров Wildberries и Ozon. Нанимается одной командой, работает в Claude Code и других ИИ-агентах.**

Считает юнит-экономику и реальную прибыль по отчётам маркетплейса, следит за ценами конкурентов, делает карточки и ТЗ на инфографику, отвечает на вопросы и отзывы покупателей, оспаривает штрафы. Всё на русском и с учётом правил площадок и российских законов.

```
> Посчитай юнит-экономику: цена 1990, себестоимость 650, комиссия 24,5%,
  логистика 90, обратная 50, выкуп 85%, хранение 12, ДРР 8%, УСН 6%

  Прибыль с единицы: 447 ₽ · маржа 22,5% · ROI 69%
  Точка безубыточности: 1 263 ₽ · цена для маржи 20%: 1 872 ₽
  Если выкуп упадёт до 70% — прибыль 412 ₽; при скидке 15% в акции — 264 ₽
```

## Установка

### Claude Code — как плагин

```
/plugin marketplace add gregreshetnyak52-crypto/WB-OZON-AI-TEAM
/plugin install wb-ozon-ai-team@wb-ozon-ai-team
```

### Claude Code — скопировать скиллы

```bash
git clone https://github.com/gregreshetnyak52-crypto/WB-OZON-AI-TEAM
cd WB-OZON-AI-TEAM && sh install.sh
```

### Другие агенты (Codex, Cursor, OpenCode и т. д.)

Скиллы сделаны в открытом формате Agent Skills: папка с `SKILL.md`. Укажите установщику папку скиллов вашего агента:

```bash
sh install.sh /путь/к/папке/скиллов
```

Можно и без установки: откройте нужный `SKILL.md` и вставьте его в начало разговора с любым ИИ-ассистентом.

## Чем это отличается от просто промптов

- **Процесс, а не одна фраза.** Каждый сотрудник работает по шагам, как опытный специалист: сначала разбирается, потом делает, потом проверяет.
- **Не выдумывает.** Цены, цифры, кейсы и характеристики товара берутся только из ваших данных. Чего не хватает — помечается `[уточнить]`.
- **Считает кодом.** Юнит-экономика и отчёты считаются программно, итоги сверяются — никаких «примерно 30% маржи».
- **Знает правила.** Модерация WB и Ozon, 152-ФЗ, закон «О рекламе», защита прав потребителей, налог УСН с маркетплейсов.
- **Не держит устаревшие тарифы в голове.** Комиссии и логистика берутся из вашего кабинета или отчёта — площадки меняют их постоянно.
- **Пишет по-человечески.** Без «Ваше мнение очень важно для нас» и «В современном мире».

## Конфиденциальность

Сотрудники — это инструкции и локальный калькулятор, а не сервис: в них нет кода, который куда-то отправляет ваши данные. Данные обрабатывает тот ИИ-агент и та модель, которыми вы пользуетесь, по их правилам. Отчёты, выписки, резюме и данные покупателей — персональные и коммерческие данные; решайте сами, что можно передавать модели.

1. Скопируйте [`docs/skill-template/SKILL.md`](docs/skill-template/SKILL.md) в `skills/<имя-латиницей>/SKILL.md`.
