# Штат

**ИИ-сотрудники для малого бизнеса. Нанимаются одной командой, работают в Claude Code и других ИИ-агентах.**

Отвечают на отзывы, пишут коммерческие предложения, разбирают заявки, анализируют конкурентов, ведут контент-план, делают карточки для Wildberries и Ozon, помогают нанимать людей и считают деньги по банковской выписке. Всё на русском и с учётом российских реалий: площадок, законов и того, как здесь принято писать клиентам.

```
> Ответь на отзывы из файла otzyvy.txt, мы — кофейня «Зерно» в Казани

  Всего 14 отзывов · 9 благодарностей · 3 критики · 2 резких негатива
  Повторяется: 3 человека жалуются на очередь утром в будни

  #1 — Анна, 5★
  Анна, спасибо, что заметили новый раф на кедровом молоке — мы с ним
  долго возились. Приходите в четверг: будет новый сезонный сироп…
```

## Установка

### Claude Code — как плагин

```
/plugin marketplace add gregreshetnyak52-crypto/Projects
/plugin install shtat@shtat
```

### Claude Code — скопировать скиллы

```bash
git clone https://github.com/gregreshetnyak52-crypto/Projects shtat
cd shtat && sh install.sh
```

### Другие агенты (Codex, Cursor, OpenCode и т. д.)

Скиллы сделаны в открытом формате Agent Skills: папка с `SKILL.md`. Укажите установщику папку скиллов вашего агента:

```bash
sh install.sh /путь/к/папке/скиллов
```

Можно и без установки: откройте нужный `SKILL.md` и вставьте его в начало разговора с любым ИИ-ассистентом.

## Чем «Штат» отличается от просто промптов

- **Процесс, а не одна фраза.** Каждый сотрудник работает по шагам, как опытный специалист: сначала разбирается, потом делает, потом проверяет.
- **Не выдумывает.** Цены, цифры, кейсы и характеристики товара берутся только из ваших данных. Чего не хватает — помечается `[уточнить]`.
- **Знает российские правила.** 152-ФЗ о персональных данных, закон «О рекламе», требования ТК РФ к вакансиям, правила модерации маркетплейсов.
- **Пишет по-человечески.** Без «Ваше мнение очень важно для нас» и «В современном мире».

## Конфиденциальность

Скиллы — это инструкции, а не сервис: в них нет кода, который куда-то отправляет ваши данные. Данные обрабатывает тот ИИ-агент и та модель, которыми вы пользуетесь, по их правилам. Выписки, резюме и данные клиентов — персональные и коммерческие данные; решайте сами, что можно передавать модели.

## Как добавить своего сотрудника

1. Скопируйте [`docs/skill-template/SKILL.md`](docs/skill-template/SKILL.md) в `skills/<имя-латиницей>/SKILL.md`.
2. Заполните роль, входные данные, процесс, формат результата и правила.
3. Проверьте: `python3 scripts/validate.py`.

Подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md).
