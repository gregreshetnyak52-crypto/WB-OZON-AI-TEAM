# Как помочь проекту

Спасибо, что хотите сделать WB-OZON-AI-TEAM лучше. Больше всего проекту нужны:

1. **Новые сотрудники** — скиллы для задач селлеров и малого бизнеса, которые встречаются каждую неделю.
2. **Реальные примеры.** Попробовали скилл на своём бизнесе — расскажите в issue, что получилось хорошо, а что нет (без персональных данных клиентов).
3. **Знание ниш.** Вы продаёте одежду, электронику, косметику, товары для дома — подскажите, чего не хватает именно вашей категории.

## Новый скилл

1. Скопируйте [`docs/skill-template/SKILL.md`](docs/skill-template/SKILL.md) в `skills/<имя>/SKILL.md`.
   Имя — латиницей в kebab-case, совпадает с `name` во frontmatter: `skills/supplier-compare/SKILL.md` → `name: supplier-compare`.
2. В `description` опишите, что делает скилл и **когда его включать** — по этому тексту агент решает, использовать ли скилл. Обязательно фраза «Используй, когда…».
3. Хороший скилл:
   - описывает процесс по шагам, а не только результат;
   - задаёт формат ответа (таблица, шаблон, структура);
   - запрещает выдумывать данные и требует заглушки `[уточнить]`;
   - учитывает законы РФ, если задача их касается;
   - короче 300 строк.
4. Проверьте скилл на 2–3 реальных запросах в Claude Code или другом агенте.
5. Запустите `python3 scripts/validate.py` и тесты: `python3 -m unittest discover -s tests`.
6. Добавьте строку в таблицу сотрудников в README.

## Правки существующих скиллов

Опишите в pull request, какой запрос работал плохо, и как он работает после правки.
